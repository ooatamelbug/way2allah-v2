# تقرير التدقيق الشامل للأقسام غير المحدثة في واجهة المستخدم وتجربة الاستخدام (UI/UX)
## موقع طريق الله الإصدار الثاني (Way2Allah V2)
**تاريخ الإعداد:** 11 سبتمبر 2026  
**نطاق التدقيق:** جميع القوالب والصفحات العامة (Frontend Blade Templates & Live Routes)  
**الحالة:** تدقيق توثيقي وتحليلي شامل (Audit Only — بدون تعديل كود)

## 1. الملخص التنفيذي (Executive Summary)

خلال مرحلة التطوير السابقة لمشروع **طريق الله الإصدار الثاني (Way2Allah V2)**، تم بنجاح تحديث الهوية البصرية الرئيسية للموقع (Modern Clean Islamic UI)، والتي شملت:
- ترويسة الموقع (Header & Navigation) والقوائم الحديثة.
- مشغل الصوتيات العائم الحديث ومكونات مشغل الفيديو.
- بطاقات السلاسل والدروس الجديدة (Enhanced Series Cards).
- الصفحة الرئيسية ومحاورها الرئيسية (مع الإبقاء على قسم *أحدث المواد المفرغة* مخصصاً للمشرف/المستخدم).

ومع ذلك، أظهر التدقيق الفاحص لجميع مسارات وقوالب العرض (Blade Views) وجود **أكثر من 35 قسماً وواجهة فرعية** ما تزال تستخدم أنماطاً قديمة موروثة من الإصدار الأول (Legacy 2005–2014 Patterns) تعتمد على مكتبات قديمة مثل `Bootstrap 3.x / Metronic Portlets` وجداول HTML الصلبة، وأيقونات صورية نقطية (GIFs)، وتنسيقات داخلية مباشرة (Inline Styles).

يهدف هذا التقرير إلى حصر وتوثيق كل هذه الأقسام بدقة متناهية، وربط كل قسم بالرابط الفعلي المباشر (Live URL)، والملف المصدري (Blade Path)، وعناصر الكود الحالية، والتصميم المقترح المتوافق مع الهوية الحديثة للموقع.

## 2. معايير الهوية البصرية الحديثة للمشروع (Design System Standard)

لضمان الاتساق عبر كامل صفحات الموقع، يجب أن تتوافق كل الأقسام مع القواعد التالية:

| المعيار | النمط القديم الموروث (Legacy) | النمط الحديث المعتمد (Way2Allah V2) |
| :--- | :--- | :--- |
| **الحاويات والبطاقات** | `.portlet.box.blue` مع حدود صلبة مربعة وعنوان كلاسيكي بلون كحلي | بطاقات بيضاء ناعمة بحواف مدورة (`rounded-2xl`)، وظلال ناعمة (`shadow-sm hover:shadow-md`)، وحدود خفيفة (`border border-slate-100`) |
| **القوائم الجانبية** | `<ul class="news"><li><a class="add">` بارتفاع 18px بدون مسافات لمس | عناصر قائمة غنية كبطاقات مصغرة (`flex items-center gap-3`)، تحتوي رقماً ترتيبياً مميزاً، مساحة لمس ≥ 44px، ومؤشرات تفاعلية |
| **البيانات الوصفية (Metadata)** | خطوط متلاصقة بدون تمييز أو أيقونات رمادية باهتة | رقاقات أنيقة (Pill Badges / Chips)، أيقونات SVG دلالية متناسقة، تدرجات رمادية مقروءة (`text-slate-500 text-xs`) |
| **الجداول** | جداول HTML كلاسيكية (`<table class="table table-striped">`) متكدسة بعرض ثابت | بطاقات بيانات متجاوبة (Responsive Data Cards) على الهواتف وجداول حديثة بدون حواف خشنة على شاشات سطح المكتب |
| **الوسائط والرموز** | صور GIF قديمة متحركة (`video.gif`, `audio.gif`) وأيقونات FontAwesome قديمة (`fa-child`) | أيقونات متجهة نظيفة (Heroicons / Lucide SVG)، وأزرار تشغيل وتحميل واضحة مع إحصائيات دقيقة |

## 3. النموذج المعياري: تدقيق قسم الفتاوى (The Prime Benchmark)

كما أشار التوجيه المرجعي في الصفحة:  
`http://127.0.0.1:8000/fatawa-all-168.htm`

### 3.1. قسم "الأكثر تحميلا" وقسم "جديد المواد" في الشريط الجانبي
- **الملف المصدري:** `resources/views/question-all.blade.php` (الأسطر 90–125)
- **الكود المصدري الحالي:**
  ```html
  <div class="portlet box blue">
      <div class="portlet-title">
          <div class="caption">الأكثر تحميلا</div>
      </div>
      <div class="portlet-body">
          <ul class="news">
              @foreach($popular_questions as $item)
                  <li>
                      <a href="{{ $item->url }}" class="add">{{ $item->title }}</a>
                  </li>
              @endforeach
          </ul>
      </div>
  </div>
  ```
- **المشاكل والعيوب المرصودة:**
  1. استخدام صنف كلاسيكي `.portlet.box.blue` ذو خلفية زرقاء داكنة مسطحة تعود لعام 2012، لا تتناغم مع ألوان الموقع الدافئة الحديثة.
  2. عناصر القائمة `<a class="add">` لا تتعدى مساحة النقر فيها `height: 18px` مع `padding: 0px`، مما يصعب النقر عليها في الهواتف تماماً.
  3. غياب تام لأي بيانات وصفية مساعدة (مثل: اسم المفتي، التصنيف الفرعي، عدد المشاهدات، تاريخ الإضافة).
  4. عدم وجود أرقام ترتيبية جذابة (Ranking Badges: 1، 2، 3...).
- **الحل والتطوير المقترح:**
  استبدال المكون بـ `<x-content.premium-panel>` مع تصميم بطاقات مصغرة:
  - إضافة شارات الترتيب (Badges) لأول 3 مواد بألوان برونزية/ذهبية مميزة.
  - إظهار سطر بيانات وصفية خفيف أسفل العنوان (اسم المفتي + أيقونة تحميل/استماع + عدد التنزيلات).
  - زيادة مساحة اللمس التفاعلية لتكون بطاقة كاملة قابلة للنقر مع تأثير حركة لطيف (`transition-all hover:translate-x-1`).

### 3.2. جدول قائمة الفتاوى والأسئلة (Main Content Area)
- **الكود الحالي:**
  ```html
  <table class="table table-striped text-center">
      <thead>
          <tr>
              <th width="5%">م</th>
              <th width="65%">عنوان السؤال</th>
              <th width="30%">المفتي</th>
          </tr>
      </thead>
      ...
  </table>
  ```
- **المشاكل:**
  - وجود كود ميت وعناصر فارغة: `<h1></h1>` فارغ تماماً يتم عرضه أعلى شريط المسار.
  - وجود تنسيقات مضمنة قسرية مثل `style="line-height: 2.2 !important;"`.
  - على الهواتف الذكية يتحول الجدول إلى خطوط متزاحمة تصعب القراءة.

## 5. خطة التحديث والتحويل البرمجي المقترحة (Modernization Roadmap)

### المرحلة الأولى: تحديث المكونات المشتركة والشريط الجانبي (Shared UI Tokens)
1. إنشاء مكون موحد للوحات الجانبية المتميزة: `components/content/sidebar-ranking.blade.php` لاستخدامه بديلاً عن `.portlet.box.blue ul.news`.
2. تنظيف وإعادة صياغة `<x-home.section-card>` ليتطابق مع نمط البطاقات الحديث.
3. التخلص من جميع استدعاءات الصور القديمة (`video.gif`, `audio.gif`, `fa-child`) واستبدالها بحزمة أيقونات SVG خفيفة.

### المرحلة الثانية: تحديث قطاع الفتاوى والأسئلة (Fatawa Overhaul)
1. إعادة بناء صفحة الفتوى الفردية `question-show.blade.php` من الصفر بصفتها أعلى الصفحات احتياجاً وتفتقر لأي تنسيق حالي.
2. ترقية القوائم الجانبية للأكثر تحميلاً وجديد الفتاوى في `question-all.blade.php`.
3. تحويل جدول الفتاوى إلى كروت متجاوبة تضمن سلاسة القراءة على الجوال وجمال العرض على سطح المكتب.

### المرحلة الثالثة: إصلاح صفحات الاستفتاءات والصفحات التعريفية والمعالج
1. إعادة كتابة صفحة "عن الموقع" وتنظيف أوسمة Word القديمة.
2. بناء واجهة استطلاعات رأي راقية في مجلد `engagement/polls/`.
3. تصحيح أخطاء JavaScript المنهارة في صفحة المعالج `wizard.php`.
