## Additional fixes found during the wider audit

| Issue and evidence | Completed fix |
| --- | --- |
| Advanced search clipped its close control and lower controls in landscape; at 667×375 the old card started above the viewport | Moved the dialog outside the scrolling/filtered header. Added viewport/safe-area sizing, a bounded flex card, persistent header, and scrollable body. Date fields wrap. |
| Search dialog focus could remain on the page | Opening now focuses the close control on mobile and title input on desktop, after the dialog becomes visible. Background content becomes inert. Tab/Shift+Tab loop inside, Escape closes, and focus returns to the trigger. The delayed focus callback checks the dialog is still open. This was the final bug completed before stopping. |
| Header search's required department field contained only its placeholder, preventing valid searches | Populated it from a shared `SearchDepartments::OPTIONS` list also used by the controller. Supported department behavior is unchanged. |
| Preacher cards were wider than their grid at 320px (a 353px card inside a 244px grid) | Allowed grid tracks/cards to shrink and long Arabic names to wrap. Applies to lecture and fatwa author directories. |
| Lecture list action extended offscreen at 320px (left edge −66px) | Mobile rows now use an icon/title grid, wrapped metadata, and a full-width action. Desktop retains horizontal rows. |
| Share-page banners were wider than the available space | Images scale down to their container while preserving aspect ratio. |
| Ramadan schedule text was clipped by nested Bootstrap negative margins | Scoped mobile row margins, table sizing, wrapping, and metadata spacing to the schedule. |
| Chat-room discovery cards had inconsistent nested gutters | Scoped mobile row and column spacing to align the discovery sections. |
| Small mobile form text can trigger iOS input zoom | Scoped mobile inputs/selects/textareas to 16px. This is a code mitigation; physical iOS behavior was not verified. |
| Search results form lacked a responsive layout | Added a styled, bounded search form with two desktop columns and one mobile column, and responsive result cards/images. |
| Search pagination returned HTTP 405 | Search is POST-only, but its pagination used GET links. Search pagination now submits the current filters and CSRF token to the requested page using buttons. Other pagination retains links. Empty sections on the current page are suppressed. |
